# La Tavola Italiana

Site estático de um restaurante italiano fictício, desenvolvido utilizando apenas HTML e CSS.

## Sobre o projeto

O La Tavola Italiana é um cardápio online simples, criado como projeto acadêmico para praticar a criação de sites estáticos e o uso do Git e GitHub.

O site apresenta pratos da culinária italiana organizados em diferentes categorias.

## Páginas

- Início
- Entradas
- Pratos Principais
- Sobremesas

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
